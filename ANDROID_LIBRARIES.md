# Android Libraries

A curated list of additional Android libraries, complementing the main [README](README.md).

- [Groupie](https://github.com/lisawray/groupie) - Simple, flexible bindings for RecyclerView
- [RxBinding](https://github.com/JakeWharton/RxBinding) - RxJava binding APIs for Android UI widgets
- [RxRelay](https://github.com/JakeWharton/RxRelay) - RxJava 2 Relay implementations
- [kotlin-logging](https://github.com/MicroUtils/kotlin-logging) - Lightweight logging framework for Kotlin
- [Arrow](https://github.com/arrow-kt/arrow) - Functional companion to Kotlin's standard library
