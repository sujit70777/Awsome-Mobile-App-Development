# Testing

Testing tools and frameworks for Android and Kotlin projects.

- [Robolectric](https://github.com/robolectric/robolectric) - Unit test framework that runs Android tests on the JVM.
- [KotlinTest](https://github.com/kotlintest/kotlintest) - Flexible and comprehensive testing tool for Kotlin.
- [Spek](https://github.com/spekframework/spek) - A Kotlin specification framework for the JVM.
- [AssertJ Android](https://github.com/square/assertj-android) - Extension for AssertJ for Android specific tests.
- [Spoon](https://github.com/square/spoon) - Distributed instrumentation test runner for Android.
- [Truth](https://github.com/google/truth) - Fluent assertions library for Java and Android.
- [Accessibility Test Framework](https://github.com/google/Accessibility-Test-Framework-for-Android) - Library to check Android views for accessibility issues.
- [screenshot-tests-for-android](https://github.com/facebook/screenshot-tests-for-android) - Screenshot testing library for Android.
